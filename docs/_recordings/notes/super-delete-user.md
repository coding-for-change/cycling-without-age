# super-delete-user

- Account: superadmin (Sanne Superadmin)
- Start URL: /admin/members
- Duration: ~22 s

## Steps
1. Members page (All chapters).
2. In the "Everyone in the chapter" table, click the search icon in the **Person** column header. Type "Anna Augsburg". The table filters to one row (Anna Augsburg · Chapter admin · Augsburg – Haus am Park).
3. Click **Anna Augsburg**. The person page opens: name, email, "No phone number", a **Roles** panel ("Augsburg – Haus am Park · Chapter admin" with **Take admin rights** and **Remove from chapter**) and a **History** list ("Clara Country (DE) sent an invitation", "An email went out — Invitation").
4. Click the trash icon (**Delete user**) in the header.
5. A dialog titled "Delete Anna Augsburg for good?" opens: "Their account, roles, requests and history go with them. Rides already ridden stay on the record." The red box "This also deletes, for good:" lists "1 chapter membership".
6. "Type DELETE-ANNA-AUGSBURG to confirm": type `DELETE-ANNA-AUGSBURG`. Click **Delete user**.
7. Toast: "Anna Augsburg is gone." Back on Members, the search now shows "Nothing matches."

## Rules / notes seen on screen
- You can't delete your own account ("You can't delete your own account.").
- Ridden rides stay on the record; the account, roles, requests and history are removed.
