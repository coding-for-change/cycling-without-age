# super-pool

- Account: country (Clara Country (DE))
- Start URL: /admin/locations/pools
- Duration: ~40 s

## Steps
1. Locations › **Pools** tab. Text: "Shared depots for the chapters of your country. Hand out the code; you decide who gets in." Table columns: Name, Waiting, Address, Chapters, Trishaws, Code.
2. Click **New pool**. A drawer titled **New pool** opens: "A depot shared by several chapters of one country. You get a code to hand out."
3. **Name**: "Depot Augsburg Mitte".
4. **Address**: type "Bahnhofstraße Augsburg" and pick the first result ("Bahnhofstraße, 86150 Augsburg, Germany"). A map with the pin appears (hint "Pick a result to place the pin; drag the pin to fine-tune.").
5. **How to find the entrance**: "Blue gate next to the bakery".
6. (Other optional fields: Photo of the entrance, Access code "Door or key-safe code. Only admins and pilots see it.", Access notes, When bringing it back, and the switch **Members may manage trishaws**: "Admins of member chapters may add, edit and move the trishaws in this pool.")
7. Click **Start pool**. Toast: "Depot Augsburg Mitte is ready." The pool's detail page opens.
8. The properties column shows a **Pool** panel. Under **Pool code** is the code (format `DE-XXXX-XX`) with **Copy** and **New code** buttons and the text "Chapters in the same country join with this code. You still approve every request." Below it is the **Members may manage trishaws** switch.
9. (Between takes, not recorded: the Augsburg chapter sent a join request with this code via Locations › **Join a pool** › Pool code › **Send request**. The page is reloaded.)
10. A **Waiting for you 1** panel appears: "These chapters asked to use this pool. They can't book its trishaws until you answer." It shows the row "Augsburg – Haus am Park" with **Decline** and **Approve**.
11. Click **Approve**. A drawer titled "Let Augsburg – Haus am Park use this pool?" opens with "Its admins will see the access notes and can book the pool's trishaws." and an optional note field "A note for Augsburg – Haus am Park (optional)". Click **Approve**. Toast: "Augsburg – Haus am Park may now use the pool."
12. Click the **Members may manage trishaws** switch. Toast "Saved." with **Undo**, and "Saved now" next to the header.

## Rules / notes seen on screen
- Pools belong to a country, not a chapter. Country admins (and superadmins) create them.
- Chapters join with the pool code and every request needs the country admin's approval (Approve / Decline, optional note).
- "New code" replaces the code (old code stops working).
- Members may manage trishaws: off by default. When on, admins of member chapters may add, edit and move the pool's trishaws.
- Data cleanup: the pool was removed after the recording.
