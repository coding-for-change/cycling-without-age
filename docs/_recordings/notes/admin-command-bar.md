# admin-command-bar

- Account: chapterAdmin (Anke Admin, München – Seniorenheim Sonnenhof)
- Start URL: /admin/rides

1. On the Rides page, the bottom of the sidebar shows the hint "⌘ K for anything".
2. Press ⌘K (Ctrl+K on Windows). The command bar opens with the search field "Search for a page or an action" and groups "Create", "Go to" (also "Perspective", "Account" further down).
3. Type "trishaw". The list filters to "Create": "Add a trishaw", "Add a trishaw model", "Join a trishaw pool", and "Go to": "Trishaws".
4. Click "Add a trishaw". The Trishaws page opens with the "New trishaw" drawer already open (fields Name, Frame number, Model, Location, Photo, Description; button "Add trishaw").
5. Press Esc to close the drawer.
6. Press ⌘K again, type "members", press Enter. The Members page opens.

Notes:
- Matching also uses keywords: "bike", "fleet", "damage", "garage", "access code" etc. find the related pages.
- ↑/↓ and Enter work in the list; Esc closes it. ⌘K toggles it.
