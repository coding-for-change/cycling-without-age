- Account: chapterAdmin (Anke Admin)

1. On "Trishaws" (tabs "Trishaws", "Models", "Week plan"; table columns Trishaw, Model, Wheelchair, Location, Status, Damage), click "New trishaw" (red, top right).
2. Drawer "New trishaw" — "Give it a name the pilots will recognise and say where it is kept."
3. "Name": "Zugspitze" (placeholder "Frieda").
4. "Frame number": "TB-2025-00419" — hint "Stamped on the frame. It can't be changed later."
5. "Model": click the field ("Search models…"), type "Trio", pick "Triobike Taxi" (the list shows seats, e.g. "2 seats").
6. "Location": open it (default is the chapter's default location "Seniorenheim Sonnenhof") and pick "Garage Lindwurmstraße". Only the chapter's own locations are listed.
7. (Optional "Photo": "Photos of this very trishaw — its colour, stickers, any marks — so pilots recognise it. Without photos the model's photos are shown.")
8. "Description": "Blue frame, rain cover in the side bag" (placeholder "What sets this one apart — colour, accessories, quirks").
9. Click "Add trishaw" (disabled until name and model are set).
10. Toast "Zugspitze has joined the fleet." and the trishaw's detail page opens: name, model · location · "In the fleet since …", sections Photos, Description, Calendar ("Rides this trishaw is booked for, week by week."), History; right column "About" (Status Ready, Frame number, Model, Location, Seats, Wheelchair, About the model) and "Damage" ("No open damage. Ready to ride as far as anyone knows." + "Report damage").
