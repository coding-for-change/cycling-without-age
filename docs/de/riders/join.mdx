Auf dem Plakat Ihrer Ortsgruppe ist ein QR-Code. Er bringt Sie direkt zu Ihrer Ortsgruppe, so dauert der Beitritt nur wenige Minuten.

<video autoPlay muted loop playsInline className="mx-auto w-full max-w-xs rounded-3xl border border-gray-200 dark:border-gray-800" src="/videos/rider-join-qr.mp4" />

## Schritte

1. Scannen Sie den QR-Code auf dem Plakat, oder öffnen Sie den Beitrittslink, den Ihre Ortsgruppe Ihnen geschickt hat.
2. Tippen Sie unter **Kommen Sie mit auf eine Ausfahrt** auf **Mit dieser Ortsgruppe fahren**.
3. Geben Sie Ihre E-Mail-Adresse oder Telefonnummer ein und tippen Sie auf **Fortfahren**.
4. Tippen Sie den 6-stelligen Code ein, den Sie bekommen.
5. Setzen Sie bei allen drei Zusagen ein Häkchen und tippen Sie auf **Fortfahren**.
6. Füllen Sie **Vorname**, **Nachname**, **Geburtstag** und **Geschlecht** aus und tippen Sie auf **Fortfahren**.
7. Tippen Sie auf **Passkey einrichten**, oder auf **Jetzt nicht**, um das später zu erledigen.

Ihre Startseite zeigt jetzt Ihre nächste Fahrt, Gruppenfahrten, die Sie buchen können, und **Ortsgruppe**.

<Note>
Eine der Zusagen betrifft die Sicherheit: Die Fahrten werden von geschulten Freiwilligen gefahren, und Sie stimmen den Sicherheitsregeln Ihrer Ortsgruppe zu.
</Note>

## Gut zu wissen

- Kein Plakat zur Hand? [Melden Sie sich an](/de/getting-started/sign-in), tippen Sie auf **Ich möchte Passagier werden** und wählen Sie Ihre Ortsgruppe unter **Wo sollen wir Sie abholen?**
- Sie richten das für einen Elternteil oder einen Menschen ein, um den Sie sich kümmern? Siehe [Für jemand anderen buchen](/de/riders/booking-for-someone-else).
