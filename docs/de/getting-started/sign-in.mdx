Du meldest dich ohne Passwort an. CWA GO schickt dir einen Code, oder dein Gerät meldet dich mit einem Passkey an.

<video autoPlay muted loop playsInline className="mx-auto w-full max-w-xs rounded-3xl border border-gray-200 dark:border-gray-800" src="/videos/pilot-sign-in.mp4" />

## Mit einem Code anmelden

1. Öffne CWA GO und tippe auf **Anmelden**.
2. Gib deine E-Mail-Adresse oder Telefonnummer ein und tippe auf **Fortfahren**.
3. Tipp den 6-stelligen Code aus der E-Mail oder SMS ein. Sobald die letzte Ziffer drin ist, meldet er dich von selbst an.

Kein Code da? Warte kurz und tippe auf **Neuen Code senden**. Falsche Adresse eingegeben? Tippe auf **Andere E-Mail-Adresse oder Nummer verwenden**.

## Mit einem Passkey anmelden

Wenn du einen Passkey angelegt hast, tippe auf dem ersten Bildschirm auf **Passkey verwenden**. Dein Handy oder Computer fragt nach Fingerabdruck, Gesicht oder PIN. Wie du einen anlegst, steht unter [Dein Konto](/de/getting-started/your-account).

<Note>
Ein Code gilt 10 Minuten. Du kannst höchstens 3 Codes pro Minute anfordern. Danach siehst du **Zu viele Versuche. Versuchen Sie es in einer Minute erneut.**
</Note>

## Gut zu wissen

- Auf einem Gerät bleibst du 90 Tage nach deiner letzten Nutzung von CWA GO angemeldet.
- Du kannst auch auf **Weiter mit Google** tippen.
- Wenn sich die Nutzungsbedingungen ändern, siehst du bei der nächsten Anmeldung **Wir haben unsere Nutzungsbedingungen aktualisiert**. Setz das Häkchen bei **Ich akzeptiere die Nutzungsbedingungen** und tippe auf **Fortfahren**.
- Erst mal umschauen? Tippe auf dem Willkommensbildschirm auf **Ohne Anmeldung umsehen**.
