A new chapter needs a name and an address, then someone to run it. Country admins open chapters in their own country, superadmins anywhere.

<video autoPlay muted loop playsInline className="w-full rounded-xl border border-gray-200 dark:border-gray-800" src="/videos/super-new-chapter.mp4" />

## Create the chapter

1. Open **Chapters** in the sidebar and click **New chapter**.
2. Type the **Chapter name**. The **Web address** below fills in from the name.
3. To change the web address, click the pencil, type a short one and click the check mark. **Free** means nobody uses it yet.
4. In **Find the address**, type the street or the care home's name and pick the right result. **City** and **Country** fill in by themselves.
5. Drag the pin on the map to fine-tune. The address follows.
6. Set **How far it rides** with the slider. The circle on the map shows the riding area.
7. Click **Create chapter**, or press ⌘↵.

The done screen shows the chapter's QR code and join link. Use **Print the poster** for the care home wall, or **Save QR code as PNG**. Click **Open chapter** to go on.

<Note>
If the circle reaches into another chapter's area, you see "Overlaps with …" and the distance. You can still save. Agree with the other chapter who rides where.
</Note>

## Invite the first chapter admin

<video autoPlay muted loop playsInline className="w-full rounded-xl border border-gray-200 dark:border-gray-800" src="/videos/super-chapter-invite-admin.mp4" />

1. Pick the new chapter in the sidebar's scope switcher. See [Switch between chapters](/en/organisation/scopes).
2. Open **Members** and click **Invite someone**.
3. Fill in **Their name** and **Email address**.
4. Under **Role**, tick **Chapter admin** and untick **Pilot**. Leave both ticked if they will also ride.
5. Click **Send the invitation**.

CWA GO creates their account right away and emails them a link to join. They show up in the list as **Chapter admin**. Point them to the [chapter admin's first week](/en/chapter-admins/first-week).

## Good to know

- Only the name and the address are required. Care home, description and logo can follow later on the chapter page.
- The web address must be unique. If it shows **Taken**, pick another one.
- Is the address in a country that isn't in CWA GO yet? A superadmin adds it on the spot with the button below the address, for example **Add Austria**. A country admin is asked to get a superadmin to add it first.
